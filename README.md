# Plain Planner

> **Work in progress.** Not yet released or listed in the Obsidian community plugins.

Plain Planner builds a plain-text plan for every day in a single note. It fills each day with tasks from your weekly, monthly and yearly routines, adds holidays and marks days off, then helps you decide what to do with the tasks you did not finish.

There are no calendar views, colors or timelines: just a simple, step-by-step list of what to do today.

The interface and the note format will be available in English and Polish.
